# Bienvenida a Jademd

**Jademd** es un gestor de conocimiento modular de alto rendimiento inspirado en Obsidian, construido con:
- **Backend:** Rust (Tokio, Axum, Apache OpenDAL, Petgraph)
- **Frontend:** React 19, TypeScript, Tailwind CSS y CodeMirror 6
